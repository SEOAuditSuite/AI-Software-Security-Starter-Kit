# Security Policy and Responsible Reporting

This repository contains **security guidance and prompts**, not an executable vulnerability scanner or hosted service.

If you discover a security issue in this repository's instructions or examples, please avoid posting sensitive exploit details or real secrets in a public issue. Contact the repository maintainer using a private reporting method **once one is configured**. No private contact address is assumed or published here.

Scope: documentation integrity, unsafe example commands, misleading security assurances, and dangerous instructions. Vulnerabilities in third-party projects used with this toolkit belong to those projects' maintainers and disclosure processes.

No guarantee, formal audit, or certification is implied. Active tests against external systems require explicit authorization.
