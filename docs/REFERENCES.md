# Security Guidance References

These are **external starting points**, not an endorsement, certification or proof that a specific application meets their requirements. Confirm the current version and applicability when performing an assessment.

- [OWASP Application Security Verification Standard](https://github.com/OWASP/ASVS/releases) — verification requirements.
- [OWASP Secure Coding with AI](https://cheatsheetseries.owasp.org/cheatsheets/Secure_Coding_with_AI_Cheat_Sheet.html) — AI-assisted secure development.
- [OWASP API Security](https://owasp.org/API-Security/) — API risks and recommended controls.
- [OWASP Secure Coding Practices](https://github.com/OWASP/www-project-secure-coding-practices-quick-reference-guide) — engineering guidance.
- [GitHub Code Security Documentation](https://docs.github.com/en/code-security) — repository security settings and scanning options.
- [OSV](https://osv.dev/) — open-source vulnerability information.
- [GitHub Actions security hardening](https://docs.github.com/en/actions/security-for-github-actions/security-guides/security-hardening-for-github-actions) — CI permissions and untrusted input considerations.

External links were catalogued from official/reference locations; live availability and current-version verification are a separate publication check.
