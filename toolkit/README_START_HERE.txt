AI SOFTWARE SECURITY STARTER KIT v1.1 — START HERE
Roman Urdu mein aasan 1, 2, 3 guide

YE KIT KYA KARTI HAI?
AI ko batati hai ke software secure tarike se kaise banana hai, kaise test karna hai, aur launch se pehle kaunse results dekhne hain. Aapko report mein clear PASS, FAIL ya INCOMPLETE milega — actual tests ke evidence ke saath.

FOLDER MEIN 4 FILES HAIN:
1. 01_AI_Software_Security_Standard.md = Complete security rules + release gates.
2. 02_AI_Instructions.txt = Naya ya purana software banwane ke ready messages.
3. 03_SECURITY_TEST_INSTRUCTIONS.txt = Software banne par security test karwane ka ready message.
4. README_START_HERE.txt = Ye asaan guide.

A. BINA PROJECT BANAYE, NEW CHAT MEIN NAYA SOFTWARE
1. ChatGPT / Claude / kisi AI ki new chat kholo.
2. '01_AI_Software_Security_Standard.md' ATTACH karo.
3. '02_AI_Instructions.txt' kholo aur 'A. NEW SOFTWARE' wala message copy karo.
4. Apne software ka idea message mein likh kar SEND karo.
5. Confirm karwao AI ne actual standard read kiya. Plan approve karne ke baad hi coding karwao.
6. Software ban jaye to neeche Section D follow karo: TEST lazmi hai.

B. PURANA SOFTWARE (JAISE SEO AUDIT SUITE V5 / V6 / V6.1 / V6.1.1)
1. Relevant actual code/repository aur security standard AI ko accessible do.
2. '02_AI_Instructions.txt' ka 'B. EXISTING SOFTWARE' paste karo.
3. Pehle read-only assessment mangwao. Existing features aur old tests ka record banao.
4. Security changes ke liye pehle approval do; bina ijazat code na badle.
5. Har version ke real code ko separately assess/test karo. Sirf version name kafi nahi.

C. CHATGPT PROJECT KE SAATH
1. '01_AI_Software_Security_Standard.md' ko Project Sources mein add karo.
2. '02_AI_Instructions.txt' ka 'C. CHATGPT PROJECT' section Project Instructions mein paste karo.
3. Jab actual tool banane ya check karne lago, AI ko relevant source code accessible do.
4. Software complete ho to Section D ka test prompt bhejo.

D. SOFTWARE KA SECURITY TEST KESE KARWANA HAI? (IMPORTANT)
1. Usi chat/agent mein jao jahan software ka code available hai.
2. '01_AI_Software_Security_Standard.md' aur '03_SECURITY_TEST_INSTRUCTIONS.txt' attach karo (agar pehle se accessible nahi).
3. '03_SECURITY_TEST_INSTRUCTIONS.txt' ka 'SECURITY TEST — READ-ONLY FIRST' message copy/paste kar do.
4. AI pehle TEST PLAN dega. Dekho kis local/test environment par tests honge. Kisi live website ya doosre ke system par test ki permission na do.
5. Aap scoped tests approve karo. AI real scanning aur synthetic data se automated tests execute karega (tools available hon to). Jo test nahi chal sakta, report mein NOT RUN likhe.
6. Report mango. Usmein proof (tool output, test results, affected file references) dekho.
7. Agar FAIL aaye to 'AFTER A FAILURE' prompt use karo. Fix approve karo, phir RETEST karwao.
8. Final result samjho:
   PASS = defined necessary tests pass, release candidate verified; launch ab bhi aapki approval se.
   FAIL = important security problem baqi; launch rok do.
   INCOMPLETE = abhi required checks ka proof poora nahi; launch approve na karo.
9. Sirf AI ka keh dena 'secure hai' kaafi nahi — test results check karo.

E. KISI AI MEIN FILE UPLOAD NA HO TO
1. Security standard ko text editor mein kholo aur poora content chat mein paste karo.
2. Phir 02 ka relevant message paste karo. Testing par 03 ka prompt paste karo.
3. AI ko check karwao ke uske paas full instructions aur relevant source code waqai hain.
4. Sirf filename ya computer ka folder path likh dene se dusra AI file nahi dekh sakta.

F. FILES KO KAHAN RAKHNA HAI?
1. ZIP download karke extract karo.
2. Apne computer par ek stable folder mein master copy rakho.
3. Har new app/chat mein zaroori files attach karo; Project mein sources ke taur par add kar sakte ho.
4. Agar future mein newer kit aaye, purani copy ko backup mein rakho aur version check karo.

YAAD RAKHO:
Build -> Test -> Fix (if needed) -> Retest -> PASS/FAIL/INCOMPLETE -> Aapki release approval.
Security ka result actual scope aur evidence par based hota hai; PASS ka matlab testing clear hai, har future unknown attack ki guarantee nahi.
